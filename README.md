# Online Course Analytics

## Project Overview
This project analyzes online course data to identify enrollment trends, course performance, ratings, pricing, and completion rates using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis

## Key Analysis
- Course-wise student enrollment
- Category-wise course performance
- Average course ratings
- Course pricing analysis
- Completion rate analysis

## Key Insights
- Machine Learning has the highest student enrollment.
- AI courses have the highest average rating.
- Marketing has the highest average category-wise enrollment.
